# self-Documented-Parser

For an university course, ACU, I asked to my professor to begin this project: writing a compiler, that was the main purpose but after some meetings we changed landing point as developing a Parser.
I suggested this kind of parser, it produces a documentation in Latex from the comments of Haskell code and obviously import the code in the paper.
The key idea is: I'm pretty lazy, a lot so as Haskell is and I don't want to write a report about the work so I used mine commented parser to produce the report by itself. I hope you'll enjoy this short trip in Functional Language, Monaids, Applicative, Parser worlds.

Please notice than haskell code and latex code have same weight, they're indeed the "same file".
